最新版：LuaLaTeX・upLaTeX・XeLaTeX用（Ver. 1.03）

  • mstf103.tar.gz（2026年10月28日更新）
  • 原稿スタイルの解説及びスタイルファイルの使い方の説明（PDF）

交通流数理研究会の原稿スタイルファイルmstf.styと，そのサンプルsample.texです． 既定の構成はLuaLaTeX＋jlreqです． タイトル，氏名，所属，概要などを書き換えて原稿を作成してください． アーカイブには，mstf.sty，sample.tex，sample.pdf，makefile，図の例dummy.pdfと旧形式のdummy.epsを同梱しています．

Ver. 1.03では，エンジン別の設定例と和文フォントの説明を追加し，図の例をPDF形式に変更しました． また，XeLaTeX＋bxjsarticleで全角幅の設定に失敗していた箇所を修正しています． Tectonicを使用する場合の設定例と実行手順も掲載しています．

LuaLaTeXで使う場合（既定の設定）

同梱のsample.texは，次のクラス指定になっています． jlreqはLuaLaTeXに対応し，日本語処理用のLuaTeX-jaを読み込みます．1

\documentclass[lualatex,twocolumn]{jlreq}
\usepackage{mstf}
\usepackage{graphicx}

展開したディレクトリで，次のコマンドを実行します．

lualatex sample.tex
lualatex sample.tex

sample.pdfが生成されます．2回の実行は，図番号や参考文献などの相互参照を解決するためです． LuaLaTeXではdvipdfmxオプションも，DVIからPDFへの変換操作も不要です． 同梱のmakefileを使う場合は，make pdfで生成できます．

和文フォントを指定する場合

jlreqでは\usepackage{luatexja}を重ねて指定する必要はありません． 和文フォントを明示的に選ぶ場合には，例えばクラス指定の後に次を追加します． これはLuaTeX-jaのluatexja-presetを使って原ノ味フォントを指定する例です．2

\usepackage[haranoaji]{luatexja-preset}

手動で和文フォントを指定する場合は，luatexja-fontspecの\setmainjfontや\setsansjfontを使います． fontspecで欧文フォントを指定するだけでは，和文フォントの設定にはなりません． 使用する和文フォントは，あらかじめインストールしてください．

LuaLaTeXでbxjsarticleを使用する場合は，クラス指定を次に置き換えます． ja=standardで日本語処理を有効にします．3

\documentclass[lualatex,ja=standard,twocolumn]{bxjsarticle}

このクラスで原ノ味フォントを明示する場合は，クラスオプションにjafont=haranoajiを追加します． 対応するluatexja-presetもクラスが読み込みます．

upLaTeXで使う場合

sample.tex冒頭のクラス指定を，次のいずれか一つに変更します． jlreqとbxjsarticleの両方を使用できます．1 3

\documentclass[uplatex,twocolumn,dvipdfmx]{jlreq}
% bxjsarticleを使う場合は，上の行を次の行に置き換える：
% \documentclass[uplatex,ja=standard,twocolumn,dvipdfmx]{bxjsarticle}

LuaLaTeX専用のluatexja-presetなどを追加していた場合は，その指定を外してください． コンパイルとPDFへの変換は，次の順で実行します．

uplatex sample.tex
uplatex sample.tex
dvipdfmx sample.dvi

makefileを使う場合は，make pdf TEX=uplatexを実行します． サンプルでは，日本語PDFしおり用のpxjahyperをhyperrefの後に読み込みます．

XeLaTeXで使う場合

jlreqはXeLaTeXには対応していないため，bxjsarticleを使用します． ja=standardを指定すると，日本語処理用のzxjatypeが読み込まれます．1 3

\documentclass[xelatex,ja=standard,twocolumn]{bxjsarticle}

dvipdfmxオプションは付けません．LuaLaTeX専用パッケージの指定は外し，次を実行します．

xelatex sample.tex
xelatex sample.tex

sample.pdfが生成されます．別途DVIからPDFに変換する操作は不要です． makefileを使う場合は，make pdf TEX=xelatexを実行します． 和文フォントのプリセットにはzxjafontが使われます． 例えばクラスオプションへjafont=haranoajiを追加すると，原ノ味フォントの設定とzxjafontの読み込みをクラスが行います．

Tectonicで使う場合

TectonicはXeTeXを基にした組版システムです． このサンプルでは，XeLaTeXの場合と同じbxjsarticleの設定を使用します． 必要な再実行はTectonicが自動で行います．4

sample.tex冒頭のクラス指定を，次に置き換えてください．

\documentclass[xelatex,ja=standard,twocolumn]{bxjsarticle}

クラスオプションはtectonicではなくxelatexを指定します． 既定のLuaLaTeX＋jlreqのままでは使用できないので，クラス指定を切り替え， LuaLaTeX専用パッケージを追加していた場合はその指定も外してください． dvipdfmxオプションは付けず，図にはdummy.pdfを使用します． 和文フォントの設定は，上のXeLaTeXの説明と共通です．

tectonic sample.tex

コマンドを1回実行すると，必要な再実行を経てsample.pdfが生成されます． 別途DVIからPDFへ変換する操作は不要です． makefileを使う場合は，make pdf TEX=tectonicを実行します．

Tectonicは，初回や未取得のパッケージを使う際に，必要なTeX資源をダウンロードしてキャッシュします． その際はネットワーク接続が必要です． 単一ファイルの上記手順では，Tectonic.tomlの作成は不要です． ログを残して確認したい場合は，tectonic --keep-logs sample.texと実行してください．

エンジンを切り替える際は，前の実行でできた.aux，.outなどの補助ファイルを削除してください． make cleanでも削除できますが，生成済みのsample.pdfとsample.dviも削除するので，必要に応じて保存してから再生成してください．

スタイルの説明

投稿原稿について

原稿は最終的にPDF形式で投稿してください．LaTeXを使う場合は，本研究会のスタイルファイルを使うと便利です． Wordなどを使う場合も，なるべくサンプルと同じ体裁にしてください．

LaTeX原稿には，次のファイルを使用します．

  • mstf.sty：スタイルファイル
  • sample.tex：サンプルのTeXソース
  • dummy.pdf：サンプルで使用する図（図を使わない場合は不要）

使用するエンジンと文書クラスに加え，mstf.styが読み込むiftex，図用のgraphicxなどが必要です． エンジン別の設定は，上の説明とsample.tex冒頭のコメントを参照してください．

原稿の体裁

投稿原稿には，和文タイトル，和文氏名，和文所属，和文概要，英文タイトル，英文氏名，英文所属，英文概要，本文，参考文献の順に記載してください．

原稿はA4判，本文のフォントは10ポイント程度とし，一段組または二段組で4ページ以内にしてください． 既定のLuaLaTeX＋jlreqで一段組にする場合は，次のように指定します．

\documentclass[lualatex,onecolumn]{jlreq}

二段組にする場合は，onecolumnをtwocolumnに置き換えます． 他のエンジン・クラスでも，それぞれのクラス指定にonecolumnまたはtwocolumnを指定してください．

タイトル，概要などは和文・英文の双方を用意してください． 概要には目的，方法，結果などを簡潔に記載し，数式・文献の番号引用，脚注，改行は入れないでください． 各内容と命令の対応は次のとおりです．

内容 命令
和文タイトル \title{}
英文タイトル \titleE{}
和文氏名 \author{}
英文氏名 \authorE{}
和文所属 \affiliation{}
英文所属 \affiliationE{}
和文概要 \abst{}
英文概要 \abstE{}

図の入れ方

graphicxパッケージを読み込み，figure環境の中で\includegraphics命令を使います． 図はPDF形式を用意すると，LuaLaTeX・XeLaTeX・upLaTeX＋dvipdfmxで共通に使用できます． PNG・JPEG形式の画像も使用できます．5

\begin{figure}[htbp]
  \includegraphics[width=1.0\linewidth]{dummy.pdf}
  \caption{PDF形式の図の取り込み例．}
  \label{fig_dummy}
\end{figure}

図番号は\captionが自動で付けます．本文からは図\ref{fig_dummy}で参照してください． LuaLaTeX・XeLaTeX用の原稿では，EPSを直接指定せず，PDFに変換した図を指定してください． EPSしかない場合は，例えば次のコマンドで変換します．

epstopdf dummy.eps

この変換にはepstopdfとGhostscriptが必要です．変換後は\includegraphics{dummy.pdf}と記述します． upLaTeX＋dvipdfmxではEPSも扱えますが，外部の変換環境に依存するため，PDFを用意する方法を勧めます．

参考文献の付け方

参考文献は本文の最後に「参考文献」というタイトルで掲載してください． 論文誌の場合は，著者名，雑誌名，巻号，ページ，発行年を記載し，巻号は太字にしてください． 書籍の場合は，著者名，書籍名，出版社，発行年を記載してください．

その他注意事項

ソースはUTF-8，改行コードLFです． 配布サンプルには使い方の説明も含まれます．実際の投稿原稿は，説明文を置き換えたうえでページ数と体裁を確認してください．
